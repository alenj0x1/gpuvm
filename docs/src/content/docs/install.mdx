<Steps>

1. **Enable Hyper-V** ([see below](#enable-hyper-v)) and restart.

2. **Download the installer** (NSIS `.exe`) from [GitHub Releases](https://github.com/alenj0x1/gpuvm/releases) and run it.

3. **Install Moonlight** ([see below](#install-moonlight)).

4. **Open GpuVM.** It opens without administrator rights.

</Steps>

## What the installer does

- Installs GpuVM **for the whole machine** in **Program Files**, with its own PowerShell 7, the PowerShell module, the profiles, the guest scripts, the `unattend.xml` template and the streaming component list inside.
- Registers the **GpuVM** service (`gpuvm-host.exe`), which does the Hyper-V work for the app. By default it starts when the app opens and stops when it quits (see [Preferences](/gpuvm/docs/using-the-app/#preferences)). Uninstalling removes it.
- The data that changes (labs and downloaded installers) goes to **`%ProgramData%\GpuVM`**, which is also restricted to administrators.
- The installer and the app interface are in Spanish.

<Aside type="note" title="Why Program Files">
The GpuVM service runs the module with administrator rights, so it only runs scripts and PowerShell from Program Files, which only an administrator can modify. See [Architecture](/gpuvm/docs/architecture/#security).
</Aside>

## Enable Hyper-V

Once, in PowerShell **as administrator**, then restart:

```powershell
Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V-All
```

If virtualization is off in the BIOS/UEFI, turn on Intel VT-x or AMD-V there first.

## Install Moonlight

Moonlight shows the VM on your desktop. Download it from [moonlight-stream.org](https://moonlight-stream.org), or from the repository run:

```powershell
./gpuvm.ps1 client-install
```

It installs Moonlight with winget (`MoonlightGameStreamingProject.Moonlight`). winget may ask you to accept its terms the first time.

## From the repository

Without the installer, everything uses the repository folder (CLI or development mode).

```powershell
# CLI, from PowerShell 7 as administrator
./gpuvm.ps1 check -Profile max-performance

# Build the installer (it ends up in app/src-tauri/target/release/bundle/nsis/)
npm --prefix app run tauri build

# Design the UI without Hyper-V (sample data; ?mock=empty, ?mock=noadmin)
npm --prefix app run dev

# Tests (no administrator needed)
Invoke-Pester ./tests
```
